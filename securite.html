🔐 ACL (Access Control List)

  • Liste de règles pour autoriser ou bloquer le trafic :
  • IP source
  • IP destination
  • Protocole (TCP/UDP/ICMP)
  • Numéro de port
  • Utilisation : contrôler l’accès et renforcer la sécurité

🔥 Firewall

  • Analyse le trafic entrant/sortant
  • Autorise ou bloque selon règles
  • Types : Hardware / Software

🌍 NAT

  • Traduction IP privée → IP publique
  • Types : Static, Dynamic, PAT
  • Exemple : 192.168.1.10 → 105.50.60.2

🔒 VPN

  • Tunnel sécurisé et chiffré
  • Usage : travail à distance, protection données, connexion site-to-site

🖥 SSH

  • Accès distant sécurisé
  • Port 22
  • Communication chiffrée
  • Remplace Telnet

🔌 Port Security

  • Limite appareils sur un port switch
  • Modes : Protect, Restrict, Shutdown

🚨 IDS / IPS

  • IDS : détecte et alerte
  • IPS : détecte et bloque
  • Différence : IDS = détecte, IPS = détecte + bloque
