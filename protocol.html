Les Protocoles Réseau

Site éducatif interactif avec animations

1️⃣ TCP

  • Protocole de transport fiable
  • Livraison correcte et ordonnée
  • Utilise des ACK
  • Plus lent que UDP
  • Utilisé par : HTTP, HTTPS, FTP, SSH

2️⃣ UDP

  • Transport rapide
  • Pas de garantie de livraison
  • Pas de contrôle d’erreur
  • Utilisé pour : Streaming, Jeux, VoIP

3️⃣ ICMP

  • Diagnostic réseau
  • Teste la connectivité
  • Exemple : ping

4️⃣ ARP

  • Convertit IP → MAC
  • Fonctionne en LAN

5️⃣ DNS

  • Nom de domaine → IP
  • Ex : google.com → 142.250.x.x

6️⃣ HTTP

  • Transfert pages web
  • Non sécurisé
  • Port 80

7️⃣ HTTPS

  • Version sécurisée HTTP
  • SSL/TLS
  • Port 443

8️⃣ FTP

  • Transfert fichiers
  • Non sécurisé
  • Port 21

9️⃣ SSH

  • Connexion distante sécurisée
  • Chiffré
  • Port 22

🔟 Telnet

  • Connexion distante
  • Non sécurisé
  • Port 23
